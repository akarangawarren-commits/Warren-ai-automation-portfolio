# Warren Akaranga — AI Automation Portfolio

Responsive portfolio website built with Next.js, TypeScript, Tailwind CSS, and Lucide icons.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel as a Next.js project.
3. Deploy using the default build settings.
4. Add your custom domain in Vercel project settings when ready.

## Before going live

- Replace the `WA` portrait placeholder with your own professional photo.
- Add sanitized screenshots and an optional demo video of the Make.com workflow.
- Add your LinkedIn and booking link when available.
- Confirm the public contact email and professional biography.
- Use only fictional or anonymized client data in project screenshots and demonstrations.
- Add a privacy notice before collecting visitor data via a future contact form.

The email CTA uses `mailto:`; it does not collect or transmit visitor data through a website backend. No live Make webhook is exposed. The featured project describes two previously verified successful test executions, not production performance.
